```
账号：账号名或类型

内容类型：如职场成长口播 / 一人食生活记录 / 旅行纪实
目标用户：年龄 + 场景 + 痛点
```

# 完整Vlog脚本

每段按以下格式，与分镜一一对应：

```
【时间】
0-3秒

【画面】
景别 + 场景 + 人物动作

【旁白】
口播一句

【字幕】
屏幕文字（如钩子句、关键数字、金句）

【音乐】
氛围说明（如"轻钢琴-渐强"）
```

---

# 拍摄执行建议

- **场景**：列出所需场景（每个都可在真实生活中拍摄）
- **道具**：列出需要的道具（生活化，随手可得）
- **镜头**：机位/运镜建议（固定、手持、跟拍、特写等）
- **人物动作**：关键动作提示（自然、可执行）
